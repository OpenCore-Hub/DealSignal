# DealSignal AI 助手

## 核心能力

- 对单个文档进行问答，例如：“这份合同的终止条款是什么？”
- 跨 Data Room 的多份文件检索，例如：“过去三年的收入增长情况如何？”
- 支持指定某份文件或一组文件作为问答范围。
- 返回文档名称、页码和可访问的引用来源。
- 保留聊天记录，并生成后续建议问题。
- 支持 PDF、DOCX、PPTX、Excel、CSV 和图片等格式。

## 底层流程

```text
上传文档
  -> 文档解析和向量索引
  -> 访问者在分享页面提问
  -> AI 只检索其有权限查看的文档
  -> 流式返回答案、来源和后续问题
```

## 主要业务场景

1. **融资与投资人 Data Room**

   投资人可以询问财务指标、商业模式、市场数据、股权和风险事项，减少创始团队重复回答相同问题。

2. **并购、尽调与法律审查**

   买方或顾问可以跨合同、财务报表、公司文件快速查找条款和数据，提高尽调效率。

3. **销售资料与客户方案**

   潜在客户可以针对产品手册、报价、案例、安全文档和技术方案自行提问，减少售前团队的重复沟通。

4. **客户 Onboarding 与知识资料库**

   客户可以在培训资料、操作手册和实施文档中直接获取答案。

5. **董事会或投资者关系材料**

   阅读者可以快速定位报告中的指标、变化原因和重要事项。

## 产品定位

DealSignal 解决的问题是：共享资料很多，但访问者阅读成本高，资料拥有者回答问题的成本也高。AI Agent 相当于在每个文档链接或 Data Room 旁边放置一个全天可用、受权限约束的问答助手。访问端界面将其描述为“AI Data Room Agent”。

DealSignal 的 AI 核心更偏向基于文档事实的可信问答，而不是开放式通用聊天。更准确地说，它属于“有权限约束的文档 RAG 助手”：

- 从用户有权访问的单个文档或 Data Room 多份文档中检索信息。
- 回答合同条款、财务指标、风险事项、产品资料等事实问题。
- 可以跨文档比较、汇总和归纳，而不只是摘抄原文。
- 返回文档名、页码等引用，方便核验。
- 文档中没有依据时应明确说明，而不是依赖模型常识猜测。
- 严格按访问权限过滤内容，避免泄露 Data Room 中的受限资料。

## 定位概括

> 以文档事实为边界，以可追溯引用为核心，支持跨文档分析的安全问答助手。

AI 助手可以进行一定程度的总结、比较和推理，例如分析三年收入变化，或汇总多份合同的终止条款。但这些结论仍应建立在文档证据之上。相比“回答得丰富”，DealSignal 更应优先保证答案有依据、可验证、权限正确。
